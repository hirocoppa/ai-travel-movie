# 検証結果

2026-10-18（日本時間）の開発環境で実施。

- `npm run build`：TypeScriptチェック・Vite本番ビルド成功。依存ライブラリを含むチャンクサイズの警告あり。外部CDNではなくサイト自身から配信。
- `npm test`：15件成功（時差・日時欠落、QuickTime作成時刻、時系列、素材不足、180秒への構成、旅行の時刻範囲の保持など）。
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`：4件成功。ブラウザで端末内の実処理を検証。人工画像・人工音声付きMP4をFFmpegで生成。
- モバイルサイズの画面で取り込み、日時指定・確認、編集開始、完了後の再編集を検証。横方向のはみ出しなし。ブラウザ例外なし。素材の外部通信なし。
- 写真1秒＋動画4秒の完成MP4：ffprobeでH.264 / AAC / 1280×720 / 30fps / 映像・音声とも5.000000秒を確認。
- 出力をPCMへデコードして、写真区間は無音・動画区間は音声が残っていることを確認。
- 180枚の人工写真を用いた書き出し：映像・音声・コンテナとも180.000000秒。単色テスト素材のためファイルサイズは実旅行動画より小さく、60MBの実素材検証の代わりではない。
- 非対応形式・エンコーダー不在時に明確な案内と作成ブロックを確認。
- `npm run preview`による本番ビルドでも、素材取り込み・AAC補完・MP4作成・動画再生に成功。

未検証：実際のiPhone Safari / Android、写真アプリへの実保存、実際の旅行素材の大量処理、HEIC/HEVC/HDRの端末別挙動、GitHub Actions実行、GitHub Pages公開。

実端末での受け入れ確認：最初は写真2枚・短い音声付き動画1本で、順序／音声／保存を確認。次に180秒分の素材で完成尺とメモリの安定性を確認。HEICやMOVは素材ごとにエラー案内を確認する。端末能力で失敗する場合はJPEG/H.264 MP4へ変換するかMac/PCの対応ブラウザで処理する。
